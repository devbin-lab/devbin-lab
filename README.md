## About

게임 개발을 중심으로 반복 작업을 줄이고, 실행 결과를 다시 확인할 수 있는 도구를 설계합니다.

AI가 창작자와 개발자의 판단을 대신하기보다 사용자가 작업의 주도권을 유지한 채 필요한 부분만 안전하게 위임하는 구조에 관심이 있습니다. 기능의 수보다 안정성, 검증 가능성, 명확한 권한 경계를 우선합니다.

## Featured Project

### [Aiso](https://github.com/devbin-lab/AISO)

[![Aiso release](https://img.shields.io/github/v/release/devbin-lab/AISO?style=flat-square&label=release)](https://github.com/devbin-lab/AISO/releases/latest)

개인용 GPU의 소형 로컬 모델에 맞춰 설계한 Windows 작업·조사·자동화·검증 에이전트입니다.

- Ollama 기반 로컬 추론과 작업 문서 검색을 위한 RAG
- 수동·읽기·자동 권한 모드를 통한 사용자 통제
- 도구 결과 검증, 제한된 재시도와 오류 보고
- Discord 자동화와 사용자 설치형 ComfyUI 연동
- Electron·React·TypeScript와 Python·FastAPI 기반 데스크톱 구조

범용 코딩 에이전트보다 로컬 모델이 안정적으로 수행할 수 있는 가벼운 작업을 명확한 권한과 검증 절차 안에서 제공하는 데 집중합니다.

## Principles

- AI는 창작자와 개발자의 판단을 보조하는 도구로 사용합니다.
- 로컬 AI와 클라우드 AI를 경쟁 관계가 아닌 역할이 다른 도구로 구분합니다.
- 실제로 확인하지 않은 결과를 완료된 작업으로 간주하지 않습니다.
